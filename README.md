# 🎵 Last.fm Match

Compare os artistas mais ouvidos entre dois usuários do Last.fm usando Django e a API oficial do Last.fm!!

## 🚀 Funcionalidades

- Busca top artistas de dois perfis Last.fm
- Compara e exibe os artistas em comum

## 🧠 Como funciona

Este projeto usa Django (backend) para se conectar com a API do Last.fm e processar os dados dos usuários.

## 🔧 Requisitos

- Python
- Django 
- Requests 
- Conta no Last.fm
- API Key do Last.fm
